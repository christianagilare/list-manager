# Archivos estáticos (públicos)

Los archivos en esta carpeta se sirven en la raíz de la app.

- **Icono de login**: guarda aquí el icono de BuenBlock con el nombre `buenblock-icon.png`  
  (también vale `buenblock-icon.ico` o `buenblock-icon.svg`; en ese caso cambia la ruta en `src/app/page.tsx`).

Ejemplo: si guardas `buenblock-icon.png` en esta carpeta, en el código se usa como `src="/buenblock-icon.png"`.
